FAST STUDENT ASSISTANT — WORKLOAD DIVISION
Team: Hareem, Noor
Based on: docs/PLAN.md and docs/PREPROCESSING_PLAN.md (4-week pilot, ~8 hours/week each)

======================================================================
HOW THE WORK IS SPLIT
======================================================================

HAREEM — Knowledge & Data owner
  Everything that turns raw sources into clean, cited, searchable text:
  PDF/web extraction, cleaning, chunking experiments, database schema,
  ingestion pipeline, paper catalogue.

NOOR — Retrieval, App & Agent owner
  Everything that turns the stored knowledge into answers:
  embeddings + retrieval, answer generation with citations, Streamlit UI,
  hybrid search, LangGraph agent and tools, deployment.

SHARED — Evaluation
  Both write and label the evaluation questions so neither person is
  grading only their own work. Each reviews the other's pull requests.

Interface between the two halves (agree on this in Week 1, Day 1):
  - The `chunks` table / LangChain Document format: text + metadata
    (source_id, revision_id, title, url, physical_page, printed_page,
    section_path, campus, programme, edition, fetched_at).
  - Hareem guarantees this format; Noor builds only against it.
